- BR-VAL-002/004: 오류 코드 기반으로 평면 실패 및 미검출 재촬영 안내 제공. 임의 인분 대체 없음.
- 저장 중 중복 클릭·보정 차단, 실패 시 보정 상태 유지, 완료 후 식단 이력 갱신.
- 명세서 FR-008과 18절을 현재 저장 동작으로 동기화. 이전 보고서의 확정 UI 미구현 설명은 이 보고서로 대체.

## 설계·회귀 위험·롤백

High Risk: 기존 확정 API 계약과 저장 트랜잭션 확장. 스키마/마이그레이션 및 신규 의존성 변경 없음.
선택적 필드를 추가하므로 기존 중량 없는 확정 요청도 지원한다. 동일 사용자 저장 요청은 사용자 행 잠금으로 직렬화하여 최초 저장 재시도도 중복 생성하지 않게 한다. 영향은 해당 사용자의 저장 대기 시간이다.
다른 식단을 새로 만드는 방식은 중복 이력을 만들므로 선택하지 않았다.
롤백은 함께 제공한 적용 코드 문서의 이번 변경 파일을 작업 전 버전으로 복구한다. 이후 사용자 변경이 있다면 전체 파일을 덮어쓰지 말고 해당 변경만 역적용한다. DB 마이그레이션 롤백은 필요 없다.
